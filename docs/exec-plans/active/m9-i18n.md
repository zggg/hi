# M9：国际化（i18n）

This ExecPlan is a living document.

## Purpose

- 用户可见文案支持 **zh / en**
- **默认跟随系统** `LANG` / `LC_*`；`hi.toml [locale]` 与 `HI_LOCALE` 可覆盖
- core 使用 `MessageId` + `messages::t()`，adapter/entry 按 locale 渲染

## 循环目标（每 Phase 结束必跑）

```sh
cargo test --workspace
cargo clippy --workspace -- -D warnings
./scripts/check-consistency.sh
# 手工：
HI_LOCALE=zh hi config   # 缺配置时中文错误
HI_LOCALE=en hi config   # 英文错误
```

| Phase | 循环验收 |
|-------|----------|
| **0** | `resolve_locale` 单测通过；`Config.locale` 可读写；`HiServices::locale()` 可用 |
| **1** | 缺 api_key / schema / channels 错误随 `HI_LOCALE` 切换；LLM 错误英文化 |
| **2** | Gateway 固定回复 + 审批 prompt 双语；`确认/取消` 与 y/n 均可 |
| **3** | `hi setup` / `hi gateway setup` 向导 UI 随系统语言 |
| **4** | TUI 状态栏、斜杠菜单、审批 UI 双语 |
| **5** | README 说明 locale；文档 `[locale]` 段 |
